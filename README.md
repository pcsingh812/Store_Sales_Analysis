# Store_Sales_Analysis

This project focuses on building a sales forecasting model using real-world retail data. It explores the relationship between various factors—such as oil prices, holidays, transactions, and store details—and daily sales across multiple locations. The analysis leverages data preprocessing, feature engineering, and machine learning models including Linear Regression and Random Forest. The goal is to predict future sales accurately by integrating multiple data sources and applying predictive analytics techniques covered in class.
